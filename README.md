# ORIS Homeworks

Репозиторий с домашними работами по дисциплине ОРИС (Основы разработки информационных систем).

## Структура проекта

- **HomeWork_1** — Вёрстка стартовой страницы поисковика (`search-engine`)
- **HomeWork_2** — Вёрстка страницы документации (`knowledge-netlify`)
- **HomeWork_3** — Базовый HTTP-сервер (`MyHttpServer`) с раздачей статики и конфигурацией
- **HomeWork_4** — Маршрутизация, контроллеры и обработка форм (`MyHttpServer`)
- **HomeWork_5** — Отправка почты через SMTP (`MailKit`) и контроллеры рассылки
- **HomeWork_6** — Собственный HTML-шаблонизатор (`MiniTemplateEngine`) и модульные тесты (`HttpServerTest`)
